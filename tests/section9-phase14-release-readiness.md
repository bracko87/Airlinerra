## Phase 14W — automatic dispatch transaction isolation and lifecycle (2026-11-22)

Implementation: `server/sql/section9_automatic_dispatch_event_atomic_isolation.sql` adds `automatic_dispatch_event_isolation_enabled` to the private crew release record, **false by default**. With the switch on, each candidate's preflight top-up, signed departure/arrival, fuel and crew operations run in a PL/pgSQL savepoint. A failed candidate rolls back that candidate only. The scheduler counts each rolled-back event in `atomicEventRollbacks` and `blockerCounts`; completed departure/arrival counters are incremented only after successful savepoint completion. With the switch off, prior fail-closed behavior is retained. Errors do not return their raw detail to client-visible status strings.

- `tests/sql/section9_atomic_dispatch_isolation_acceptance.sql`: **PASS**. Two independently scheduled synthetic departures: first fails after its movement insert because fuel verification fails; first movement and game-fuel top-up roll back; second movement, fuel evidence, crew tracking and booking closure persist in the test subtransaction. Replay does not duplicate. Disabled gate rethrows as before. All fixture changes rolled back.
- `tests/sql/section9_automatic_dispatch_departure_arrival_acceptance.sql`: **PASS**. Same batch separation, followed by an arrival processing cycle. The good flight records arrival, aircraft usage, arrival fuel burn, crew completion and turnaround via controlled test producers. The bad flight's arrival is blocked because its departure was never verified. Repeated cycles do not duplicate.
- Previously completed `tests/sql/section9_recovered_crew_ticket_clock_finance_acceptance.sql`: **PASS**. Actual ticket reconciliation, authoritative clock verification and real final finance posting/ledger functions run against independently verified fixture evidence, including idempotence and negative tests. These are **separate** tests; the dispatcher fixture is not wired to the complete real production receipt generators or the independent ticket/finance workers in one unbroken transaction series.
- Regression reruns: active intermediate reserve recovery and mixed-crew actual turnaround **PASS**.
- Read-only production audit: isolation=false, all seven crew release booleans=false, both dynamic-turnaround release booleans=false, contracting=false, no commercial occurrences or signed operated movements/settlements. Dispatcher continued running (30 successes and 0 failures in most recent checked half hour); no signed flight was executed. The dispatcher remains a private invoker function.

**Still blocking production enabling:** a disposable-world acceptance with real (not synthetic) source certification and booking, event signer/movement writer, fuel custody and arrival usage writers, crew binding, turnaround, actual postarrival finance-preparation and approval jobs, and one complete real settlement.
