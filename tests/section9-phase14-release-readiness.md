## Phase 14W — automatic dispatch transaction isolation and lifecycle (2026-11-22)

The scheduler counts each rolled-back event in `atomicEventRollbacks` and `blockerCounts`; completed departure/arrival counters are incremented only after successful savepoint completion. With the switch off, prior fail-closed behavior is retained. Errors do not return their raw detail to client-visible status strings.
