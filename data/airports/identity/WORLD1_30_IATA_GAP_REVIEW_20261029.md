# Airlinerra World 1 — 30 previously unreported IATA codes: research report

**Research date:** 29 October 2026. **Scope:** all 3,141 approved World 1 airports, focusing on the original 30 entries with IATA not reported.

The original 3,111 source-reported IATA values are **unverified source assertions**, not independently audited against the IATA coding directory. This pass investigated the 30 source gaps. Airport-owner claims, secondary travel-provider labels, FAA/ICAO/local identifiers and historical airport codes are **not equivalent to IATA assignment authority**.

## Critical false-code traps

- **Győr-Pér / QGY:** [Airport operator](https://lhpr.hu/en_EN/airport-data) explicitly lists QGY and LHPR. The game profile now stores `QGY` as **operator-source-reported**, not as IATA database-confirmed.
- **Pitt Meadows / YPK:** city and airport use YPK; [iFlightPlanner](https://www.iflightplanner.com/Airports/CYPK) calls it IATA while [OurAirports](https://ourairports.com/airports/CYPK/) does not. Further authority confirmation required.
- **Austin Executive / EDC:** [ch-aviation](https://www.ch-aviation.com/airports/EDC) and [Flightradar24](https://www.flightradar24.com/data/airports/edc) call EDC IATA, while FAA also uses EDC as a local identifier and other secondary sources say IATA none. Do not overwrite the blank unconditionally.
- **Pingtung North / PIF:** [historically operated civil airport](https://de.wikipedia.org/wiki/Flughafen_Pingtung), closed to civilian passenger flights in 2011. Do not infer current playable airline operations from the historical code.
- **Old Nabire / NBX:** [Indonesian aviation authority](https://hubud.kemenhub.go.id/bandara/502) now allocates NBX/WABI to **Douw Aturure**. This is not Old Nabire's current code.
- **Tabing / PDG:** [Indonesian aviation authority](https://hubud.kemenhub.go.id/bandara/239) allocates PDG to **Minangkabau**, the replacement facility. Do not transfer this code to Tabing.
- **Ho Airport / HZO:** [OurAirports change log](https://ourairports.com/airports/DGAH/changes.html) explicitly describes HZO as not a valid IATA code when it was removed.
- **Beaver Island / SJX**, **Austin / EDC**, and other US facilities: FAA three-letter IDs may exist without proof of IATA allocation. Treat the systems as distinct.
- **Aleksandrovo (fictional):** no real IATA code; never fabricate one.

## Completion gate for this one field

Do **not** call the IATA field fully green until each airport has either:
1. An assignment backed by the *current* [IATA official airport/location code search](https://www.iata.org/en/publications/directories/code-search) (or licensed IATA dataset), properly matched to the **exact facility**; OR
2. A defensible, reviewed no-assignment status, clearly different from simply "source blank"; OR
3. An explicit historical/fictional/non-applicable classification backed by suitable evidence.

Given official IATA code datasets can be access-controlled and change over time, the source-only audit is complete but the current IATA allocation verification is **still amber**. Continue with GPS after outstanding IATA cases are resolved or documented as authority-access blocked. Do not confuse IATA field readiness with airport suitability for passenger/cargo traffic.
